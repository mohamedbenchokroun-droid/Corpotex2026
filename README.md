# corpotex.ma

Site catalogue B2B de Corpotex (Yates Group, Témara, Maroc) : application JavaScript sans framework, pré-rendue en pages HTML statiques.

- `shell.html` : gabarit source ; les pages `*.html` sont générées.
- `js/data.js`, `js/products.js` : contenu et catalogue.
- `api/devis.php` : réception des demandes de devis (la configuration SMTP est sur le serveur, jamais dans ce dépôt).
